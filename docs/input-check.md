# Проверка ввода в играх (этап 1)

Цель: до того как строить редактор, убедиться, что нажатия из Game Remote доходят до игр, и узнать задержку.

## Как запустить

На ПК с Windows, в папке репозитория:

```
python -m pip install -e .
python tools/input_check.py key KeyM --delay 5
python tools/input_check.py serve
```

- `key` даёт 5 секунд переключиться в игру и три раза нажимает клавишу. Сочетание пишется кодами `KeyboardEvent.code`: `ControlLeft+KeyR`, `ArrowUp`, `F5`.
- `serve` печатает ссылки для телефона в той же Wi-Fi. В ссылке есть секрет: без него страница не может нажимать клавиши, поэтому другие устройства в сети ничего не нажмут. На странице есть кнопки «нажать» и «держать», а сверху видно время ответа. Если Windows спросит про брандмауэр, разрешите доступ в частных сетях.
- Вторая ссылка использует имя компьютера (`имя-пк.local`). Проверьте, открывается ли она с ваших телефонов: такой адрес не ломается, когда роутер выдаёт ПК другой IP.
- `--hold 60` перед командой меняет время удержания клавиши при нажатии (по умолчанию 40 мс).

Что проверить в каждой игре:

1. Нажатие (`Tap M` или своя клавиша) срабатывает в окне и в полноэкранном режиме.
2. Удержание (`Hold W`, `Hold Shift`) двигает персонажа, пока палец на кнопке.
3. Если выключить Wi-Fi на телефоне во время удержания, клавиша отпускается.
4. Если игра запущена от администратора, скрипт пишет `[ADMIN: input dropped]`.
5. Две кнопки одновременно: держите `Hold W` одним пальцем и нажимайте `Tap M` другим.
6. Удержание стрелки или другой клавиши в меню игры: повторяется ли действие, как на настоящей клавиатуре.
