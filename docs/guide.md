# Руководство по Game Remote

Game Remote — это один файл `GameRemote.exe` на ПК с Windows и страница в браузере телефона. На ПК вы собираете панель кнопок для каждой игры, на телефоне нажимаете их, и программа отправляет в игру клавиши.

## Где взять exe

Готовый `GameRemote.exe` лежит на странице [Releases](https://github.com/godsfear/game-remote/releases). Рядом с ним файл `GameRemote.exe.sha256` с контрольной суммой.

Сборку из последнего коммита делает CI: на странице репозитория откройте **Actions**, выберите последний запуск **CI** и скачайте внизу артефакт **GameRemote**. Это zip с одним файлом.

Собрать самому на Windows:

```
python -m pip install -e ".[dev]"
python tools/build_exe.py
python tools/smoke_test.py dist/GameRemote.exe
```

## Первый запуск

1. Запустите `GameRemote.exe` двойным щелчком. Файл не подписан, поэтому SmartScreen может показать «Система Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом случае».
2. Windows спросит про брандмауэр. Разрешите доступ в **частных** сетях, иначе телефон не увидит ПК.
3. В трее появится значок, а в браузере откроется страница Game Remote с QR-кодом.
4. Наведите камеру телефона на QR-код. Телефон должен быть в той же Wi-Fi. Откроется демо-панель из шести кнопок, а телефон появится на странице ПК в списке «Телефоны и планшеты».
5. Откройте Блокнот и нажмите на телефоне «Карта»: в Блокноте появится `m`. Страница на ПК показывает последние нажатия.

## Пульт на телефоне

Кнопка «⋮» в правом верхнем углу открывает настройки этого устройства: «Во весь экран» убирает адресную строку браузера, «Вибрация при нажатии» включает и выключает отклик. Там же видно, сколько миллисекунд идёт сигнал до ПК и обратно. Принятое нажатие даёт один короткий толчок, отклонённое — два, и внизу появляется причина.

Чтобы открывать пульт одним касанием, добавьте страницу на главный экран через меню браузера: у неё есть свой значок. Страница открывается по обычному `http`, поэтому Android создаёт ярлык, а не отдельное приложение: пульт откроется во вкладке браузера, и полный экран включается кнопкой в настройках.

Если связь с ПК пропала дольше чем на несколько секунд, пульт пишет, что проверить, и подключается сам, как только связь вернётся: в том числе после блокировки экрана и возвращения в Wi-Fi.

## Редактор

Страница на ПК — это редактор. Слева список игр, в середине кнопки выбранной игры, справа предпросмотр: его рисует тот же код, что и пульт на телефоне.

1. Нажмите «Добавить игру» и введите название.
2. Нажмите «Добавить кнопку», введите подпись, затем «Записать» и нажмите клавишу или сочетание на клавиатуре. Сочетания, которые браузер забирает себе (`Ctrl+W`, `Alt+Tab`), задаются в блоке «Выбрать вручную».
3. Выберите, что делает касание: «Нажать» или «Держать», цвет кнопки и при желании картинку. Подойдут PNG, JPEG и WebP; большую картинку редактор сам уменьшит. Подпись остаётся видна поверх картинки.
4. Порядок кнопок меняется стрелками или перетаскиванием в списке, число колонок — кнопками «−» и «+».

У игры можно задать обложку: она видна в списке игр на телефоне. Там же задаётся окно игры: запустите игру, нажмите «Выбрать окно» и выберите её в списке открытых окон. После этого кнопки работают, только пока активно окно этой программы, и нажатие не попадёт в чат или браузер. Без привязки клавиши идут в то окно, которое активно. Язык выбирается внизу страницы. В режиме «Авто» редактор и каждый телефон используют язык своего браузера, а выбранный язык становится общим для всех устройств.

Сохранять ничего не нужно: изменения записываются сами, и открытая на телефоне панель обновляется сразу. Удалённая игра не стирается, а переносится в `%LOCALAPPDATA%\GameRemote\trash`.

Выход: значок в трее → «Выход» или кнопка внизу страницы на ПК. Повторный запуск exe открывает страницу уже работающей программы.

Если игра запущена от администратора, Game Remote тоже нужно запустить от администратора (правая кнопка → «Запуск от имени администратора»). Иначе Windows отбрасывает нажатия, а телефон пишет причину. В списке окон такие программы помечены «запущена от администратора».

Если во время удержания кнопки активным становится окно другой программы, зажатые клавиши отпускаются сами.

## Файл панели

Редактор хранит каждую игру в папке внутри `%LOCALAPPDATA%\GameRemote\panels`: файл `panel.json` и картинки кнопок. Кнопка «Открыть папку с панелями» внизу страницы открывает её в Проводнике. Папку можно скопировать на другой ПК или править файл вручную. Имя папки: латинские буквы, цифры, `-` и `_`.

Программа перечитывает файлы сама: сохраните `panel.json`, и панель на телефоне и в редакторе обновится примерно через секунду. Если в файле ошибка, редактор покажет, в каком месте, а остальные панели продолжат работать.

Пример `panels\x4\panel.json`:

```json
{
  "name": "X4: Foundations",
  "columns": 3,
  "window": "X4.exe",
  "buttons": [
    { "id": "map", "label": "Карта", "keys": "KeyM" },
    { "id": "radio", "label": "Связь", "keys": "ControlLeft+KeyR", "color": "#2b5fd9" },
    { "id": "boost", "label": "Ускорение", "keys": "Tab", "type": "hold", "color": "#2f9e62" },
    { "id": "stop", "label": "Стоп", "keys": "Backspace", "image": "stop.png" }
  ]
}
```

| Поле | Что значит |
| --- | --- |
| `name` | Название панели, видно на телефоне |
| `columns` | Число колонок в портретной ориентации, от 1 до 8. По умолчанию 3. В альбомной помещается вдвое больше |
| `window` | Необязательно. Имя exe игры; в редакторе выбирается из открытых окон. Если задано, нажатия отклоняются, пока активно окно другой программы |
| `buttons` | Кнопки в том порядке, в котором они идут на экране |
| `id` | Имя кнопки внутри панели: латинские буквы, цифры, `-` и `_`. Не повторяется |
| `label` | Подпись, до 40 знаков |
| `keys` | Клавиша или сочетание через `+`. Модификаторы нажимаются первыми |
| `type` | `tap` — короткое нажатие (по умолчанию). `hold` — клавиша зажата, пока палец на кнопке |
| `color` | Цвет фона в виде `#rrggbb` |
| `image` | Имя файла PNG, JPEG или WebP в папке панели |
| `cover` | Поле панели, а не кнопки. Обложка игры: имя файла в папке панели |

Клавиши записываются кодами физических клавиш, как в браузере (`KeyboardEvent.code`), поэтому не зависят от раскладки:

- буквы и цифры: `KeyA` … `KeyZ`, `Digit0` … `Digit9`;
- модификаторы: `ControlLeft`, `ControlRight`, `ShiftLeft`, `ShiftRight`, `AltLeft`, `AltRight`;
- `F1` … `F24`, `Escape`, `Tab`, `Space`, `Enter`, `Backspace`, `CapsLock`;
- `ArrowUp`, `ArrowDown`, `ArrowLeft`, `ArrowRight`, `Home`, `End`, `PageUp`, `PageDown`, `Insert`, `Delete`;
- знаки: `Minus`, `Equal`, `BracketLeft`, `BracketRight`, `Semicolon`, `Quote`, `Backquote`, `Backslash`, `Comma`, `Period`, `Slash`;
- цифровой блок: `Numpad0` … `Numpad9`, `NumpadAdd`, `NumpadSubtract`, `NumpadMultiply`, `NumpadDivide`, `NumpadDecimal`, `NumpadEnter`.

Полный список — в [`src/game_remote/input/keys.py`](../src/game_remote/input/keys.py).

## Как устроен доступ

В QR-коде зашита ссылка с одноразовым кодом. Первое устройство, которое её откроет, получает собственный ключ, а код перестаёт работать: фотография экрана или пересланная ссылка никого больше не впустит. Неиспользованный код живёт пять минут, после чего страница на ПК рисует новый. Устройство хранит ключ в браузере и дальше подключается само, без QR-кода. Без ключа пульт не принимает ни одной команды.

Все привязанные устройства видны на странице ПК в списке «Телефоны и планшеты»: кто на связи сейчас и когда был в последний раз. Щелчок по имени переименовывает устройство, крестик отключает его: ключ перестаёт работать сразу, зажатые клавиши отпускаются, а устройство просит отсканировать QR-код заново. Чтобы подключить ещё одно, нажмите «Подключить ещё одно устройство». Если камера не читает код, ссылку можно скопировать кнопкой под ним и переслать на телефон; она тоже сработает один раз.

Список хранится в `%LOCALAPPDATA%\GameRemote\game-remote.sqlite3`. Самих ключей там нет, только их хеши.

Телефон, подключённый к прежней сборке с общим ключом, нужно привязать заново: отсканируйте QR-код ещё раз.

## Игры с античитом

Игры с защитой от программного ввода нажатия не видят. Так ведёт себя Undecember: страница на ПК пишет «отправлено», Windows нажатие принимает, а игра его игнорирует, в том числе когда Game Remote запущен от администратора. Обходить такую защиту программа не будет.

## Что проверить и рассказать

- Реакция антивируса и SmartScreen на exe.
- Подключить второе устройство, переименовать и отключить его. После перезапуска программы и перезагрузки роутера телефон должен подключиться сам, без QR-кода.
- Привязать панель к окну игры: вне игры телефон должен писать «Окно игры не активно», в игре кнопки должны работать. Есть ли игра в списке окон и не слишком ли много в нём лишнего.
- Открывается ли пульт по QR с первого раза. Если в списке адресов на странице ПК есть имя компьютера (`имя-пк.local`), открывается ли пульт по нему.
- Удобно ли собирать панель в редакторе и записывать сочетания.
- Вечер игры с настоящей панелью: заметна ли задержка, бывают ли пропущенные нажатия или залипшие клавиши.
- Гаснет ли экран телефона, пока пульт открыт. Страница проигрывает невидимое видео, чтобы экран не гас; сработает ли это на вашем телефоне, заранее неизвестно.
- Настройки пульта (кнопка «⋮»): какую задержку до ПК и обратно показывает пульт в домашней Wi-Fi, работает ли полный экран, чувствуется ли вибрация, как выглядит ярлык на главном экране.
- Заблокировать телефон на минуту и разблокировать: пульт должен вернуться на связь за пару секунд.
- Удобны ли размер и расположение кнопок в портретной и альбомной ориентации.
- Что происходит, если выключить Wi-Fi на телефоне с зажатой кнопкой: клавиша должна отпуститься не позже чем через 3 секунды.

Логи лежат в `%LOCALAPPDATA%\GameRemote\logs`.
